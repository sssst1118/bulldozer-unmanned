# Qt App Main (监控台)

> **Author:** dozer-dev  
> **Date:** 2026-03-15

## 概述

推土机无人驾驶控制台，1280×800 桌面应用，集成8个功能Tab + 左侧实时状态栏。

## 文件说明

| 文件 | 说明 |
|------|------|
| main.cpp | 节点入口，启动Qt应用 |
| manual_control_widget.h/cpp | 主界面 (8个Tab + 侧边栏) |
| grid_map_widget.h/cpp | 栅格地图可视化控件 |

## Tab 功能

1. **直接CAN控制** — 按住按钮直驱CAN (绕过规控节点)
2. **节点功能测试** — 自动作业/单步行走/铲刀找平 三模式互斥
3. **PID调参** — 行走PID + 铲刀PID + 桥接死区 在线调节
4. **整车状态** — 发动机转速/扭矩、变速箱、车速、电流、姿态
5. **规划参数** — 路径增益、Z字间距、容差、过载阈值
6. **车辆配置** — txt格式参数保存/加载
7. **数据录制** — rosbag一键录制，可选话题
8. **通信诊断** — 关键话题频率和超时检测

## 安全机制

- Tab切换时自动停止非当前Tab的控制定时器
- 切离Tab1自动锁定直接CAN控制
- 启动时默认锁定，需手动解锁
